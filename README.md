# プラケニル累積投与量計算ツール（日本基準版）

## 課題
医療従事者が日本国内の添付文書基準（理想体重・6.5mg/kg/day）でプラケニルの累積投与量とリスクを評価しようとしても、既存の計算ツールは米国基準（実体重・5mg/kg/day）に基づいており、そのまま使うと基準がズレた判断材料になりかねない。また用量変更があった場合の期間ごとの合算計算を手動で行うのは煩雑でミスが起きやすい。

## 目的
身長・体重から理想体重（ブローカ式桂変法）を算出し、添付文書の体重区分別基準で1日量の妥当性を判定、用量変更履歴を複数入力して期間ごとに合算した累積投与量と日本基準（6.5mg/kg/day理想体重）に対する評価を、個人情報を保存せずその場で計算できるWebアプリを、PC・iPhone・Androidのブラウザで公開する。

## 概要
フェーズ1(添付文書数値の確定)→フェーズ2(単発計算:理想体重・体重区分別基準表示)→フェーズ3(用量変更履歴の複数入力・期間ごと合算・累積量・リスク超過判定)→フェーズ4(GitHub Pages公開・複数端末動作確認)。データ保存なし・サーバーなしの静的Webアプリ。完成期日2026-10-27目標。
